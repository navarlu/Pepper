# Animation Sound Test

Run each curl from inside the bridge container:
```
docker compose -f docker/docker-compose.yml --env-file .env exec bridge curl -s -X POST http://localhost:5000/animation/<NAME>
```

Or copy-paste the full commands below. After each one, write "SOUND" or "SILENT".
